# 云端 IELTS AI Teacher

固定网址：https://ielts-ai-teacher-log007.knobbysky1.chatgpt.site/

该站点使用 Sites 的私人访问保护。API 额外检查登录身份，并按账号隔离存储。

首次打开时，在设置页输入 DeepSeek API 密钥并确认资料发送及计费说明。密钥通过 HTTPS 提交到服务端，以 AES-GCM 加密保存在云端 R2；加密主密钥使用 Sites 的 VAULT_KEY secret 配置。服务不会把 API 密钥返回到浏览器、写入学习档案或代码。更换 API 密钥可在设置页保存新值。密钥有效性在首次调用 DeepSeek 时确定。

每日按北京时间划分日期，首次打开时生成当天学习包，后续打开读取缓存。生成由用户打开页面触发，并非凌晨预生成。最多5次生成尝试/日，60次聊天尝试/日；失败请求也计入。限制采用存储计数，不能保证并发请求下的严格全局配额。配置服务商限额以控制费用。

练习含10词、650–850词目标文章（允许600–1000）、13题、原文引用与中文讲解，默认22分钟。AI输出通过字段/数量/原文引用检查，但未经独立教师审稿，仍可能有歧义或错误答案。暂停不计入用时；关闭页面时计时继续；设备时钟修改会影响计时。评分为大小写、空白规范化后的预设答案匹配，填空检查词数，合理的其他表达可能需教师复核。每题信心为选填，错误原因不会仅依据得分自动确诊。

作答和反馈保存在云端，同时在浏览器缓存当前练习和待上传记录。网络中断时当前已载入页面可继续计时作答，云端提交、首次打开、生成、实时老师需要联网。不是完整可离线安装的PWA。旧版 localhost 的 localStorage 档案不会自动进入新网址。

没有声称 ChatGPT 订阅对话可以自动读取本站记录。用户可导出 JSON 档案用于阶段复盘。每周完整教学复盘、1/3/7天词汇掌握复测、自动调整训练周数、学习档案导入、聊天历史持久化尚未实现。

## 08:00 推送接入

原 ChatGPT 的「IELTS 每日学习」任务尚未在此处修改。可将其改为每日提醒打开上述固定网址；不要声称该任务已将资料同步至本站。本站使用 DeepSeek 从已保存记录中选择下一次训练；ChatGPT任务保留提醒职责。避免另外建立重复推送。

## 开发与验证

src/ 为可维护源码；scripts/build.mjs 将页面与API打包到 Worker。运行 `node scripts/build.mjs`、`node scripts/validate-artifact.mjs`、`node scripts/test-api.mjs`。测试使用模拟存储和模拟密钥，不调用真实付费API。实际模型调用需要用户在网站里配置密钥后验证。
