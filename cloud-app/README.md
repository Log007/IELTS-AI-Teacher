# 云端 IELTS AI Teacher

固定网址：https://ielts-ai-teacher-log007.knobbysky1.chatgpt.site/

该站点使用 Sites 的私人访问保护。API 额外检查登录身份，并按账号隔离存储。

首次打开时，在设置页输入 DeepSeek API 密钥并确认资料发送及计费说明。密钥通过 HTTPS 提交到服务端，以 AES-GCM 加密保存在云端 R2；加密主密钥使用 Sites 的 VAULT_KEY secret 配置。服务不会把 API 密钥返回到浏览器、写入学习档案或代码。更换 API 密钥可在设置页保存新值。密钥有效性在首次调用 DeepSeek 时确定。

每日按北京时间划分日期，首次打开时生成当天学习包，后续打开读取缓存。生成由用户打开页面触发，并非凌晨预生成。最多5次生成尝试/日，60次聊天尝试/日；失败请求也计入。限制采用存储计数，不能保证并发请求下的严格全局配额。配置服务商限额以控制费用。

练习含10词、650–850词目标文章（允许600–1000）、13题、原文引用与中文讲解，默认22分钟。AI输出通过字段/数量/原文引用检查，但未经独立教师审稿，仍可能有歧义或错误答案。暂停不计入用时；关闭页面时计时继续；设备时钟修改会影响计时。评分为大小写、空白规范化后的预设答案匹配，填空检查词数，合理的其他表达可能需教师复核。每题信心为选填，错误原因不会仅依据得分自动确诊。

作答和反馈保存在云端，同时在浏览器缓存当前练习和待上传记录。网络中断时当前已载入页面可继续计时作答，云端提交、首次打开、生成、实时老师需要联网。不是完整可离线安装的PWA。旧版 localhost 的 localStorage 档案不会自动进入新网址。

没有声称 ChatGPT 订阅对话可以自动读取本站记录。用户可导出 JSON 档案用于阶段复盘。每周完整教学复盘、1/3/7天词汇掌握复测、自动调整训练周数、学习档案导入、聊天历史持久化尚未实现。

## 08:00 推送接入

原 ChatGPT 的「IELTS 每日学习」任务尚未在此处修改。可将其改为每日提醒打开上述固定网址；不要声称该任务已将资料同步至本站。本站使用 DeepSeek 从已保存记录中选择下一次训练；ChatGPT任务保留提醒职责。避免另外建立重复推送。

## 开发与验证

src/ 为可维护源码；scripts/build.mjs 将页面与API打包到 Worker。运行 `node scripts/build.mjs`、`node scripts/validate-artifact.mjs`、`node scripts/test-api.mjs`。测试使用模拟存储和模拟密钥，不调用真实付费API。实际模型调用需要用户在网站里配置密钥后验证。

## 官方材料优先（更新）

页面默认展示 IELTS.org 与 British Council 官方来源链接。它们是官方样题/练习，不声称为历年实考真题。已取消打开页面和保存密钥后自动生成 AI 练习；用户主动点击“AI 原创补充练习”才会调用模型。官方页面的作答尚未同步至本站，不能把链接入口描述为已经内置官方题库。前文有关自动生成的描述以本节为准。

生成连接现在以 NDJSON 即时响应并每5秒发送进度，避免整包生成期间长时间没有下行数据。DeepSeek 请求显式关闭 thinking，输出截断时明确报错。修复后的尝试计数独立于旧版，最多10次/日。真实模型调用仍需用户验证。

## 原创仿真主训练（最新偏好）

用户接受接近真实考试的仿真材料，因此恢复按天载入/生成主训练。要求650–850词、13题、至少3类；生成后增加一轮模型校对，仍需通过程序检查。它不是经过考生标定的官方难度，不能保证对应某个雅思分数。生成与复核涉及两次DeepSeek调用，可能需2–5分钟并增加API用量。已有当天学习包不覆盖，避免丢失正在作答的内容；新增校对只应用于新生成材料。

## 文章检查失败修复

草稿不再在校对前因为字数不符而直接退出；校对接收程序测量的词数和错误，仍失败时自动修订一次（最多三次模型调用）。最终仍需650–850词、13题和至少3类。错误区分标题、正文格式与实际词数，并不保存未通过检查的学习包。新增回归测试覆盖短草稿经校对恢复、二次修订成功、最终失败不落库。

## 数量错误的分组修复

题目数或词汇数不符合要求时，不再只靠重写整包修正。错误的题目部分分成4道判断、4道填空、5道选择生成；错误的词汇部分分成两组各5个生成。保留文章及其他已有正确数量的组件，合并后仍必须通过13题、10词及原文证据检查。分组修复会增加调用次数和等待时间；它不等于独立教师对语义的审核。回归测试覆盖12题/9词组合失败恢复，以及数量正确时不额外调用。

## 选项格式兼容与草稿恢复

把选择题答案字母或唯一匹配的选项文本转换为完整选项；支持选项字典、判断题大小写、填空题空 options 数组。只转换唯一明确映射，未知答案与重复文本造成的歧义仍被拒绝，错误显示题号。保存每阶段私人草稿，重试优先从草稿校正，不再必然重新生成整包。未通过检查的草稿不进入正式学习记录。

文章仍以650–850词为生成目标，但程序接受600–1000词的合理浮动，避免875词等合适篇幅仅因略超目标而反复重写。页面明确显示目标与容许范围。

## 单词发音

每个每日词汇旁有发音按钮。使用浏览器 SpeechSynthesis，优先设备提供的本地英式英语音色，其次其他英式音色，再退回可用英语音色或设备默认英语。可重复播放或点击停止，不调用 DeepSeek、不申请麦克风权限、不存储语音。设备/浏览器可能使用其在线音色服务；没有可用英语语音或播放失败时会显示提示。已保存学习包同样具有按钮，无需重新生成。

## 交卷与复盘流程（2026-11-02更新）

交卷后本机立即按题显示文字标记、颜色、参考答案与原文解释，并向 /api/grade 保存客观记录。该记录标记 feedbackPending，整体主观反馈可随后填写，填写时不会重新覆盖已交答案或得分。断网时保留待同步作答。页面重载后可从云端恢复已提交结果。

学习档案内先由老师用表单逐题询问错因；覆盖错题及标记为猜测、犹豫的正确题。用户可以选择“不确定”，不要求虚构原因。提交后 /api/diagnosis 结合用户自述、作答和近期记录生成建议，并保存到当前记录。生成模型建议前不会自动付费调用；每天最多10次复盘。该分析是教学建议，不是已经证实的心理/能力诊断。已有逐题解析为题目讲解，与用户实际错因分开。

每日词汇前固定加入1–2句解题策略提示。训练日期按北京时间：11月2–8日维持入门（目标650–850词，容许600–1000）；11月9日起目标800–950，最低800词，最多1100。默认计时仍为22分钟。已经保存的当天材料不覆盖，后续日期的新生成材料使用日期规则。

## 个性化分析后的连续对话

个性化分析下面新增“回答老师／继续追问”按钮和回复输入框。每次复盘按练习记录隔离；服务端加载原始作答、原分析及最近16条对话继续答疑，一次优先追问一个问题。用户与老师的完整后续对话单独保存到云端，刷新后点击按钮可重新载入，JSON导出包含followUp。每次发送消耗DeepSeek余额，每日60次/每次练习60轮限制。草稿保存在本机；请求ID保护同一条发送重试，版本检查避免过时页面直接覆盖新对话。R2不提供此流程的跨设备原子锁，仍建议不要同时在多个窗口发送。
