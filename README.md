# IELTS AI Tutor MVP

双击 `index.html` 即可离线使用。示例文章为原创演示材料，包含 4 题和 5 分钟限时，不是正式 IELTS 试卷。点击开始计时，作答后完成练习并提交简短反馈。答案、正误、时间、文章信息和反馈保存在当前浏览器；学习记录页显示历次成绩，导出按钮生成 JSON 档案。简答题使用列出的固定答案匹配，其他合理表述可能被判错，请参照解析核对。

计时按设备时钟计算，关闭页面或断网仍继续；更改系统时间可能影响结果。浏览器清除站点数据、更换浏览器或设备可能丢失记录，建议定期导出。导出目前仅供备份和人工查看，尚不支持导入、同步或跨设备恢复。勿将个人档案公开分享。

## DeepSeek 实时老师（仅本机）

安装 Node.js 18 或更新版本。在 PowerShell 中，自己输入以下命令，将提示中的密钥输入窗口设为隐藏，然后访问 http://127.0.0.1:3210：

```powershell
$secret = Read-Host 'DeepSeek API Key' -AsSecureString
$ptr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secret)
try { $env:DEEPSEEK_API_KEY = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($ptr) } finally { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($ptr) }
node server.js
```

关闭终端结束服务。密钥只放在该终端进程环境里，不要贴到聊天、代码或 GitHub。每次启动需要重新设置。聊天时当前文章、题目、当前答案和最近 10 条记录会发送至 DeepSeek，并可能产生费用。聊天记录仅在当前页面内存中保留。服务只监听本机，不具备公网用户身份验证，禁止直接部署到公网。GitHub 仓库只同步代码，不同步浏览器里的学习记录。原有“尚未实现”描述以本节为准。

## 一键启动（Windows）

双击项目目录中的 `打开雅思老师.bat`。首次启动时粘贴 DeepSeek API 密钥并按 Enter；Windows 会把密钥加密保存到项目目录的 `.deepseek-key` 文件，绑定当前 Windows 用户和电脑。之后双击即可打开，无需手动输入命令。请不要上传或分享密钥文件；它已被 Git 忽略。换电脑或 Windows 账户后需重新设置。需要更换密钥时，先结束正在运行的 Node 服务，再删除 `.deepseek-key` 并重新启动。程序在后台运行，仅监听本机 3210 端口；关闭浏览器页面不会结束后台服务。首次设置和每次使用均需安装 Node.js。若端口已被其他程序占用，请关闭该程序再试。

老师在电脑宽屏时固定在右侧；窄屏时点击右下角“问老师”打开。以上一键启动仅适用于这台电脑，不是已部署到互联网的云服务。GitHub 上更新代码也不会自动更新到你的本机，请确保使用最新的本地项目文件。
